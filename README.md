# Notification Alert releases

Public downloads for Notification Alert. The application source stays in a private repository. This repository is only the release channel.

Each GitHub release tag is the version number, such as `v1.0.0`. The Windows file attached to the release is `NotificationAlert.exe`.

The installed app checks this repository once when it starts. If the latest release is newer than the running build, it downloads that exe, replaces itself, and starts again.
